# Scene assets

Wooden Desk by [Jaximus](https://www.cgtrader.com/designers/jaximus), downloaded by the project owner from [CGTrader](https://www.cgtrader.com/free-3d-models/interior/office-interior/wooden-desk-ce5c4807-c033-40a7-a6ff-e39ae4daca14). Upstream licensing remains applicable.

The supplied GLB is self-contained. The web derivative fixes unintended transparency, retains the geometry and material maps, and resizes the embedded textures (tabletop colour 2048px, other maps 1024px, unused emission maps 256px). Runtime material setup also enforces opaque, depth-writing surfaces.

Source asset remains unchanged in Downloads. Binary models stay on the owner's media server, outside Git and Vercel assets. Model metadata and the book's Controls menu include the creator credit.

The desk trial is a separate preview. Add `?desk=off` to compare the previously accepted hardback scene; add `?desk=off&motion=on` for its cinematic movement.
